## 🏦 Nubank Clone  

Uma recriação da interface do Nubank utilizando tecnologias web modernas, focada em um design responsivo e fiel à experiência do usuário.  

## 🌐 Demonstração  
Acesse o projeto ao vivo em: [Nubank Clone](https://andre-studionerd.github.io/nubank/)  

## 🚀 Tecnologias  
- HTML5  
- CSS3  
- JavaScript  

## ✨ Funcionalidades  
- Design inspirado na interface do aplicativo Nubank  
- Responsividade para diferentes tamanhos de tela  
- Navegação suave entre seções  
- Estrutura modular para facilitar a manutenção e expansão do código  

## 📥 Como rodar o projeto localmente  
1. Clone o repositório:  
    ```bash
    git clone https://github.com/Andre-StudioNerd/nubank.git
    ```
2. Acesse o diretório do projeto:  
    ```bash
    cd nubank
    ```
3. Abra o arquivo `index.html` no navegador.  

## ⚠️ Aviso Legal  
Este projeto é apenas uma recriação educacional e não tem nenhuma afiliação com o Nubank. Todos os direitos sobre a marca e identidade visual pertencem ao Nubank.
